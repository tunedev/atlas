# Epic 13 — The web UI — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `atlas -serve` serves an embedded Svelte UI on loopback. Through it, someone who
never opens a terminal can review judged subjects, decide on them, see calibration, and
consent to data leaving the machine. The surface is a second one through Epic 12's seam, and it
changes nothing under `internal/core/`.

**Architecture:** The new inbound adapter is `internal/adapters/inbound/web`. Every screen and
action is a blueprint that a pack's view file declares and that runs through the shared
`*app.Runner` with a per-run `WithProgress` copy. Reads go through two new generic outbound
tools: `index.find` and `docs.get`. Transport is connect-go, with `proto/atlas/web/v1/ui.proto`
as the contract. The composition root supplies everything the web package cannot import: the
pack loader, the runner, the egress table, and a browser-backed `ports.Permission`.

**Tech Stack:**

- Go 1.27
- `connectrpc.com/connect` v1.21.0
- `google.golang.org/protobuf` v1.36.12
- buf v2 config (the `buf` 1.72 binary is already installed)
- Svelte 5.57, Vite 8.3, `@sveltejs/vite-plugin-svelte` 7.3
- `@connectrpc/connect` and `@connectrpc/connect-web` 2.2
- `@bufbuild/protobuf` and `@bufbuild/protoc-gen-es` 2.15

**Spec:** `docs/specs/2026-09-27-epic-13-web-ui.md`

## Global Constraints

- Nothing under `internal/core/` changes. A task that needs it stops and reports a finding.
- `internal/adapters/inbound/web` and its subpackages import, inside the module, only
  `internal/core/...` and their own subtree (`TestInboundAdaptersStayIsolated`). They never
  import `packfile`, `mcpserve`, `config`, `pidlock`, `telemetry`, or any outbound adapter.
- Generated Go lives at `internal/adapters/inbound/web/uiv1` (messages and connect code in one package, via
  protoc-gen-connect-go's empty `package_suffix`), because `TestEveryPackageHasAKnownHome`
  allows no other home. No `.go` file goes under the repo-root `web/`.
- There is no bind beyond loopback: `Web.Addr`'s host must parse as a loopback IP, and nothing
  overrides that.
- The browser never names a pack path, a tool, or an undeclared var.
- `Model.APIKey` never appears in any response, stream message or log.
- Every wrapped error carries its component prefix: `web: `, `index.find: `, `docs.get: `,
  `config: `.
- `ctx context.Context` is the first parameter of every blocking call, and is never stored in a
  struct.
- No job-hunt vocabulary in any `.go` file, or in `web/src` once Task 11 extends the scan. Test
  fixtures use neutral subjects (logbook, shelf).
- Generated code and `internal/adapters/inbound/web/dist/` are committed. `go build` needs
  neither `buf` nor Node.
- Global npm or toolchain installs are the machine owner's step. `npm ci` inside `web/` is
  reported as a command for the owner, and not run by an agent.
- No emojis. Comments describe current behaviour only.

## Rulings made while planning

| # | Ruling | Why | Cost if wrong |
|---|---|---|---|
| P1 | The server gets one `*app.Runner` and calls `WithProgress` per run | Epic 12 made `WithProgress` return a copy (`cfa2c94`), so the spec's "fresh runner per run" is already true of a copy | None: one line |
| P2 | The composition root injects the pack loader as `func(path string) (domain.Blueprint, error)` | `web` may not import `packfile` (a sibling surface) | None |
| P3 | Use connect-go v1.21.0, not v2 | v2 is `v2.0.0-alpha.1`. Latest stable wins over latest alpha. | A later port of the generated code |
| P4 | The consent gate is per server, not per blueprint. While any hosted endpoint is unacknowledged, every `Run` refuses with `needs_acknowledgement`. | Epic 10's `pack.each` runs child packs whose tools the parent's steps do not name, so a blueprint walk would miss them. Gating per server cannot leak. | One extra click before a run that would not have reached the model |
| P5 | "Hosted" means the model base URL's host is not `localhost` or a loopback IP literal. There is no DNS lookup. | A name that resolves to loopback today may not tomorrow. Treating unknown names as hosted is the safe side. | A LAN engine behind a hostname asks for consent once |
| P6 | An acknowledgement is a `docs.put` at `atlas/egress/<sha256(endpoint)[:16]>.json`, with kind `egress` and fields `endpoint` and `discloses` (a JSON array). It is read back with `index.find`. | `ports.Docs` has no not-found error to branch on, and an index row answers "is there one" cleanly | None: the index rebuilds from the record |
| P7 | The drafted PDFs (Epic 10's `out_dir`) are served from one configured root, `Web.FilesRoot`, through `os.Root`, as attachments only. The `file` widget reads a path relative to that root. | The spec's `Document` covered record paths only, but Epic 9 and 10 write PDFs to disk. `os.Root` confines every read below the root. | A spec amendment. Recorded in the increment note. |
| P8 | A screen's last result is cached server-side per (view, screen, params). `state.<path>` bindings read that cache, never the browser. | `state` values then cannot be forged by the browser | A stale cache needs the screen reloaded, which the error says |
| P9 | The Svelte source uses `<script lang="ts">`, with no `typescript` package and no `svelte-check` | Vite and Svelte strip types themselves. TypeScript 7 plus svelte-check is an unknown this epic does not need. | A type error found at runtime. The widgets are small. |
| P10 | Epic 10's actions (draft, declare sent, promote a rule) are Task 14, which runs only after PR #47 is merged | The spec says they arrive as view-file edits. Their vars are Epic 10's to fix. | None |

## Review Focus

1. **A request from a web page the user visits.** A foreign `Origin`, a foreign `Host`
   (rebinding), or a missing cookie is refused before any handler runs. Pinned in Task 5.
2. **A browser that sends a var, pack or path the view did not declare.** It is refused, and
   nothing runs. Pinned in Tasks 4 and 6.
3. **A permission ask with nobody watching.** It denies when the stream closes or times out,
   and never hangs a run. Pinned in Task 7.
4. **Two tabs clicking at once.** Runs serialise and the second is told its queue position.
   Pinned in Task 6.
5. **A `file` path that climbs out of `Web.FilesRoot`** (`../`, absolute, or a symlink). It is
   refused by `os.Root`. Pinned in Task 9.

```go
package tools

import (
	"context"
	"encoding/json"
	"fmt"
	"strconv"
	"time"

	"github.com/tunedev/atlas/internal/core/ports"
)

// IndexFind returns the index rows of one kind whose fields equal every
// value in match. It reads the derived index, never the record.
type IndexFind struct{ index ports.Index }

func NewIndexFind(index ports.Index) *IndexFind { return &IndexFind{index: index} }

func (f *IndexFind) Name() string { return "index.find" }

func (f *IndexFind) Invoke(ctx context.Context, with map[string]string) (any, error) {
	if with["kind"] == "" {
		return nil, fmt.Errorf("index.find: no kind")
	}
	match, err := parseFields(with["match"])
	if err != nil {
		return nil, fmt.Errorf("index.find: %w", err)
	}
	limit := 0
	if raw := with["limit"]; raw != "" {
		if limit, err = strconv.Atoi(raw); err != nil || limit <= 0 {
			return nil, fmt.Errorf("index.find: limit must be a positive integer, got %q", raw)
		}
	}
	recs, err := f.index.Find(ctx, ports.Query{Kind: with["kind"], Match: match, Limit: limit})
	if err != nil {
		return nil, fmt.Errorf("index.find: %w", err)
	}
	rows := make([]map[string]any, len(recs))
	for i, r := range recs {
		rows[i] = map[string]any{
			"path": r.Path, "rev": string(r.Rev), "kind": r.Kind,
			"fields": r.Fields, "when": r.When.UTC().Format(time.RFC3339),
		}
	}
	return map[string]any{"rows": rows}, nil
}

// DocsGet reads one document from the record, at its latest revision or at
// rev. A body that is valid JSON is also returned parsed, as doc.
type DocsGet struct {
	docs     ports.Docs
	maxBytes int64
}

func NewDocsGet(docs ports.Docs, maxBytes int64) *DocsGet {
	return &DocsGet{docs: docs, maxBytes: maxBytes}
}

func (g *DocsGet) Name() string { return "docs.get" }

func (g *DocsGet) Invoke(ctx context.Context, with map[string]string) (any, error) {
	path := with["path"]
	if path == "" {
		return nil, fmt.Errorf("docs.get: no path")
	}
	var body []byte
	var err error
	if rev := with["rev"]; rev != "" {
		body, err = g.docs.GetAt(ctx, path, ports.Revision(rev))
	} else {
		body, err = g.docs.Get(ctx, path)
	}
	if err != nil {
		return nil, fmt.Errorf("docs.get: %s: %w", path, err)
	}
	if int64(len(body)) > g.maxBytes {
		return nil, fmt.Errorf("docs.get: %s is %d bytes, over the %d-byte bound", path, len(body), g.maxBytes)
	}
	out := map[string]any{"path": path, "text": string(body)}
	var doc any
	if json.Unmarshal(body, &doc) == nil {
		out["doc"] = doc
	}
	return out, nil
}
```

```go
func (w WebConfig) validate(packPath string) error {
	if !w.Serve {
		if packPath == "" {
			return fmt.Errorf("config: no pack path; pass -pack or -serve")
		}
		return nil
	}
	if packPath != "" {
		return fmt.Errorf("config: pass -pack or -serve, not both")
	}
	if len(w.Views) == 0 {
		return fmt.Errorf("config: -serve needs at least one view file; pass -web-views")
	}
	host, _, err := net.SplitHostPort(w.Addr)
	if err != nil {
		return fmt.Errorf("config: web addr %q: %w", w.Addr, err)
	}
	if ip := net.ParseIP(host); ip == nil || !ip.IsLoopback() {
		return fmt.Errorf("config: web addr %q is not a loopback IP; atlas serves this machine only", w.Addr)
	}
	if w.RunTimeout <= 0 || w.AskTimeout <= 0 || w.HeaderTimeout <= 0 {
		return fmt.Errorf("config: web run, ask and header timeouts must be positive")
	}
	return nil
}
```

```proto
syntax = "proto3";

package atlas.web.v1;

option go_package = "github.com/tunedev/atlas/internal/adapters/inbound/web/uiv1;uiv1";

// UIService is the browser's only way into atlas. A run names a screen or
// action a view file declares; it never names a pack, a tool or a path.
service UIService {
  rpc Views(ViewsRequest) returns (ViewsResponse);
  rpc Run(RunRequest) returns (stream RunResponse);
  rpc Answer(AnswerRequest) returns (AnswerResponse);
  rpc Acknowledge(AcknowledgeRequest) returns (AcknowledgeResponse);
  rpc Document(DocumentRequest) returns (DocumentResponse);
}

message ViewsRequest {}

message ViewsResponse {
  // The loaded view files as JSON, in the shape the UI renders. Their
  // widgets are pack data, so they are not modelled field by field here.
  string views_json = 1;
  repeated Endpoint egress = 2;
  // Whether downloads from the files root are available.
  bool files_enabled = 3;
}

message Endpoint {
  string endpoint = 1;
  bool hosted = 2;
  repeated string tools = 3;
  bool acknowledged = 4;
}

message RunRequest {
  string view = 1;
  string screen = 2;
  // Index into the screen's actions; -1 runs the screen itself.
  int32 action = 3;
  map<string, string> params = 4;
  map<string, string> inputs = 5;
}

message RunResponse {
  oneof event {
    Queued queued = 1;
    Step step = 2;
    Ask ask = 3;
    Done done = 4;
    NeedsAcknowledgement needs_acknowledgement = 5;
  }
}

message Queued { int32 ahead = 1; }

message Step {
  string step_id = 1;
  string tool = 2;
  string status = 3;
  string error = 4;
}

message Ask {
  string id = 1;
  string tool_name = 2;
  string kind = 3;
  string summary = 4;
}

message Done { string state_json = 1; }

message NeedsAcknowledgement {
  repeated string endpoints = 1;
  repeated string discloses = 2;
}

message AnswerRequest {
  string id = 1;
  bool allow = 2;
}

message AnswerResponse {}

message AcknowledgeRequest { string endpoint = 1; }

message AcknowledgeResponse {}

message DocumentRequest {
  // "record" reads a record path through docs.get; "file" reads a path
  // relative to the configured files root.
  string source = 1;
  string path = 2;
}

message DocumentResponse {
  bytes body = 1;
  string media_type = 2;
  string name = 3;
}
```

```go
type bindings struct {

	state                  any
}

func resolve(vars map[string]string, b bindings) (map[string]string, error)
func lookup(v any, path string) (any, bool)
```

**The YAML shape.** This is the spec's shape. A widget is a single-key map: the key is the kind,
and the value is its spec. `Widget.UnmarshalYAML` takes the one key as `Kind`. `Run` paths
resolve against the view file's directory.

**Validation** (`LoadViews` fails at the first problem, naming the file and the screen):

- `ID` is unique across files. Screen ids are unique within a file.
- A widget's `Kind` is one of `table fields badge list text bins document file`.
- Every `open.screen` names a screen in the same view, and its `param` keys are that screen's
  `Params`.
- Every `run` loads through `load`. Every key in a `vars` map is a key of the loaded blueprint's
  `Vars`, so binding an undeclared var fails at boot.
- Every binding value starts with one of these sources:
  - `param.`: must be in the screen's `Params`;
  - `input.`: must be one of the action's `Input` names; a screen's own vars may not use it;
  - `state.`: allowed only in actions;
  - `const.`;
  - `server.`: one of `store_root` or `files_root`.

**Resolution.**

- `param.x`, `input.x` and `server.x` take the value, and a missing one is an error naming it.
- `const.rest` is the literal `rest`.
- `state.a.b` uses `lookup`: a dotted walk through `map[string]any`, where a numeric segment
  indexes `[]any`. A string result is used as is; anything else is JSON-encoded.
- An input with `Options` must equal one of them.

**Guards** (`guard.go`). One middleware wraps everything, in this order:

1. Set the security headers on every response:
   - `Content-Security-Policy: default-src 'self'; frame-ancestors 'none'`
   - `X-Content-Type-Options: nosniff`
   - `Referrer-Policy: no-referrer`
2. If `r.Host != host`, respond `421 Misdirected Request`. This blocks DNS rebinding.
3. On a non-`GET`/`HEAD` request, an `Origin` that is not `"http://" + host` gets `403`. This
   blocks cross-site writes.
4. `POST /session` with a JSON body `{"token": "..."}`. On a constant-time match
   (`subtle.ConstantTimeCompare`), set `atlas_session=<token>; HttpOnly; SameSite=Strict;
   Path=/` and respond `204`. Otherwise respond `401`.
5. Paths under `/atlas.web.v1.UIService/` need an `atlas_session` cookie that matches in
   constant time, or `401`.
6. Everything else is served from the embedded `dist` with `http.FileServerFS`. Static files
   carry no data.

No `Access-Control-*` header is ever set.

### Task 6: `Run`: resolve, queue, stream progress, cache the result

**Files:**
- Create: `internal/adapters/inbound/web/run.go`, `internal/adapters/inbound/web/run_test.go`
- Modify: `internal/adapters/inbound/web/server.go`

**Interfaces:**
- Consumes: `(*app.Runner).WithProgress(func(domain.StepEvent)) *app.Runner`,
  `(*app.Runner).Run(ctx, domain.Blueprint) (*domain.State, error)`, `State.Outputs()`, and
  `Blueprint.WithVars`.
- Produces:
  - `(*Server).Run(ctx, *connect.Request[uiv1.RunRequest], *connect.ServerStream[uiv1.RunResponse]) error`
  - an unexported `slot`: a `chan struct{}` of capacity 1, plus an `atomic.Int32` count of
    runs waiting;
  - an unexported state cache, keyed by `view|screen|sorted params`.

**Flow:**

1. Find the view and screen by id. When `action >= 0`, find the action. An unknown id gets
   `connect.CodeNotFound`.
2. Resolve vars with `resolve`:
   - `params` and `inputs` come from the request;
   - `server` comes from `Deps.Server`;
   - for an action, `state` comes from the cache. A cache miss is `CodeFailedPrecondition`,
     with "reload the screen".
   - A request `param` the screen does not declare, or an `input` the action does not declare,
     is `CodeInvalidArgument`.
3. Check the consent gate (Task 8 fills in `s.unacknowledged()`). If any endpoint is
   unacknowledged, send `NeedsAcknowledgement` and return nil.
4. Load the blueprint (`Load(path)`, then `WithVars(vars)`).
5. Increment the waiting count and send `Queued{ahead: waiting-1}`. Then take the slot with
   `select` on `slot <- struct{}{}` and `ctx.Done()`. Decrement the count once it is taken.
6. Hold the slot, set the active run (for Task 7's asker), and run with
   `context.WithTimeout(ctx, cfg.RunTimeout)`, through
   `runner.WithProgress(func(e) { send(Step{...}) })`.
7. On success, marshal `state.Outputs()`, cache it under the key (screens only; actions do not
   replace the cache), and send `Done`. On failure, return `connect.NewError(connect.CodeUnknown, err)`.

`send` wraps `stream.Send` with a per-run mutex, because progress, asks and the flow above send
from different goroutines.
